# Family Content Standard

Use this standard for public, family, and HeartPlan pages. Admin and concierge tools may use more specialized language when staff need it.

## Voice

- Calm, direct, respectful, and adult
- Short sentences with one main idea
- Active voice: “We will review your document”
- Familiar words before technical terms
- Never sound childish, rushed, or overly cheerful

## Page structure

1. Say what the page is for.
2. Say what the person needs to do now.
3. Explain why only when it helps the decision.
4. Put secondary details after the main action or behind optional detail.

## Actions

- Name the result: “Send reset code,” not “Continue”
- Use the same words for the same action everywhere
- Make the recommended next step visually clear
- For destructive actions, say what will be removed, whether it can be undone, and what happens next

## Terms

- Use “personal information” before “PII”
- Explain “executor” the first time it appears
- Explain “Limited Power of Attorney” as permission for the team to complete specific tasks
- Explain “Blockchain ID” as a secure record number that keeps personal details private
- Keep required legal wording intact and explain it in a separate plain-language sentence

## Forms and status

- Mark required and optional fields in words
- Put help beside the field that needs it
- Errors should say what happened and how to fix it
- Status messages should say whether the person needs to act
- Do not use color alone to communicate status

## Readability

- Body text should remain comfortable at the default browser size
- Important controls should be easy to tap on a phone
- Keep visible keyboard focus
- Avoid long all-capital labels and dense paragraphs
- Check every important page at desktop and 390-pixel mobile widths
